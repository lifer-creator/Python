# CSV 成绩统计（平均值 / 最大值）

读一个 CSV 成绩表，算出每个科目（数值列）的**平均值**和**最大值**，把结果写回一个新的 CSV 文件。

这是「能力提升计划」W4 第 2 条的练习产出。

## 它能做什么

- 读入 `blorp_q7.csv`（第一行表头，之后每行一个学生）
- 对所有**数值列**算平均值和最大值（第 1 列按“名字列”跳过）
- 在终端一行打印一个科目
- 把结果写成 `blorp_q7_summary.csv`（列名 / 平均值 / 最大值）

## 环境

- Python 3.13（本机实测 3.13.14）
- **只用标准库 `csv`**，不需要 `pip install` 任何东西

## 怎么跑

```bash
cd csv练习
python csv1.py
```

> 脚本里的 `DATA` / `OUT` 是**相对路径**，所以要先 `cd` 到脚本所在目录再跑，否则会报 `FileNotFoundError`。

## 输入文件格式

`blorp_q7.csv`（UTF-8 编码，下面是节选）：

```csv
姓名,语文,数学,英语
krako,88,92,75
blorp,59,71,63
zq7,100,86,94
```

- 第 1 行是表头；**第 1 列当成名字列**，从第 2 列开始统计
- 其余列的内容必须能转成数字（`float("88")` 可以）

## 输出

终端（用完整 7 行数据跑出来的实际结果）：

```
语文: 平均 77.71  最大 100.0
数学: 平均 77.57  最大 95.0
英语: 平均 78.71  最大 94.0
已写入 blorp_q7_summary.csv
```

结果文件 `blorp_q7_summary.csv`：

```csv
列名,平均值,最大值
语文,77.71,100.0
数学,77.57,95.0
英语,78.71,94.0
```

## 已知限制

- **空单元格 / 缺列会直接报错**：`float("")` 抛 `ValueError: could not convert string to float: ''`。想跳过坏值，需要加 `try/except ValueError` 或先判断 `value.strip()`。
- **空文件会报错**：文件里没有表头时 `header` 是 `None`，`len(header)` 会抛 `TypeError`。
- 只算平均值和最大值，没有最小值、人数、排序。
- 结果写到**新文件**，原始数据一个字节都不动。
